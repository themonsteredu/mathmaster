# 오답 반복학습 (Math Master)

수학학원 오답 반복학습 웹앱입니다.
틀린 문제를 사진으로 올리고, 정한 횟수만큼 반복해서 풀게 하는 앱입니다.

## 기술
- Next.js (웹앱 화면)
- Supabase (데이터 + 사진 저장소)
- Vercel (인터넷 배포)

## 개발 단계
- [x] 0단계: 빈 프로젝트 세팅 + 인터넷 배포
- [ ] 1단계: 데이터 표 2개 만들기
- [ ] 2단계: 오답 업로드 화면
- [ ] 3단계: 학생 오답함 목록 화면
- [ ] 4단계: 풀이 사진 업로드 → 횟수 +1, 완료 처리
- [ ] 5단계: 원장 관리 화면
